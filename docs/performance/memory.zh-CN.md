请求字节表示业务仍需要的存储；常驻内存还包括分配器缓存与管理信息。释放 Block 后，分配器可以保留空间供后续复用。

## 混合尺寸与生命周期

16384 个 Block，十种 17–8193 B 尺寸，八轮重新分配与释放；保留 1024 个 Block，全部请求页均写入。

操作后立即取样，不额外等待或主动回收。五列依次对应初次分配、首次保留、八轮后的分配、八轮后的保留、全部释放。

在用请求存储，MiB；各平台使用相同负载：
